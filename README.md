# חוסם וידאו – אפליקציית אנדרואיד

אפליקציה שחוסמת אפליקציות וידאו ואתרי וידאו בדפדפן, עם סיסמה לפתיחת האפליקציה ולכיבוי החסימה.

## מה היא עושה
- **סיסמה** – נקבעת בהפעלה הראשונה ונדרשת בכל פתיחה. נשמרת רק כגיבוב (SHA-256 עם salt). 5 ניסיונות שגויים = נעילה לדקה.
- **חסימת אפליקציות** – יוטיוב, טיקטוק, נטפליקס, דיסני+, טוויץ', אינסטגרם, VLC ועוד (רשימה ניתנת לעריכה).
- **חסימת אתרים** – בכרום, סמסונג אינטרנט, פיירפוקס, אדג', Brave, אופרה, DuckDuckGo ועוד.
- **כיבוי חסימה / שינוי סיסמה** – רק עם הסיסמה.
- **חסימת וידאו ברמת המכשיר**:
  - זיהוי נגן וידאו בתוך **כל** אפליקציה (וואטסאפ, טלגרם, גלריה, דפדפנים, אפליקציות חדשות) – לפי רכיבי הנגן הסטנדרטיים של אנדרואיד.
  - האזנה למערכת השמע של המכשיר: כל השמעה שמסומנת כ"סרט" נעצרת ונחסמת, לא משנה מאיזו אפליקציה.
  - **מצב אפליקציות מאושרות בלבד** – כל אפליקציה שלא אושרה (כולל חדשות) לא נפתחת.
  - **מצב בעלים (Device Owner)** – אפליקציות הווידאו מוסתרות מהמערכת עצמה, האפליקציה לא ניתנת להסרה, מצב בטוח ואיפוס יצרן חסומים, ואפשר לחסום התקנת אפליקציות.
- **הגנה מפני עקיפה** – חוסמת את מסכי ההגדרות שבהם אפשר לכבות את השירות או להסיר את האפליקציה, ו"מנהל מכשיר" שמונע הסרה.

## בניית קובץ APK

### אפשרות א – Android Studio (הכי פשוט)
1. התקן [Android Studio](https://developer.android.com/studio).
2. File → Open → בחר את התיקייה `VideoBlocker`.
3. המתן לסנכרון Gradle, ואז Build → Build APK(s).
4. הקובץ ייווצר ב-`app/build/outputs/apk/`.

### אפשרות ב – GitHub (בלי להתקין כלום)
1. צור מאגר חדש ב-GitHub והעלה אליו את תוכן התיקייה (כולל `.github`).
2. בלשונית **Actions** הבנייה רצה אוטומטית.
3. בסיום – הורד את `VideoBlocker-apk` מתחתית דף הריצה.

## התקנה והגדרה בטלפון
1. העבר את ה-APK לטלפון והתקן (יש לאשר "התקנה ממקורות לא ידועים").
2. פתח את האפליקציה וקבע סיסמה.
3. לחץ "פתח הגדרות נגישות" → "חוסם וידאו" → הפעל.
   - באנדרואיד 13 ומעלה, אם האפשרות אפורה: הגדרות → אפליקציות → חוסם וידאו → ⋮ (למעלה) → "התר הגדרות מוגבלות", ואז חזור לנגישות.
4. לחץ "הפעל מניעת הסרת האפליקציה" ואשר.
5. לחץ "הפעל הגנת הגדרות" (אחרון, כי היא חוסמת את מסכי ההגדרות של האפליקציה).
6. מומלץ: בהגדרות הסוללה של האפליקציה בחר "ללא הגבלה", כדי שהמערכת לא תכבה את השירות.
7. לחסימה הכי חזקה – הגדר מצב בעלים (למטה).

## הגדרת מצב בעלים (פעם אחת, דרך מחשב)
זה מה שהופך את החסימה לחסימה ברמת המערכת: אפליקציות הווידאו נעלמות מהמכשיר, ואי אפשר לעקוף דרך מצב בטוח, איפוס יצרן או הסרה.

1. **הסר זמנית את כל החשבונות** מהטלפון: הגדרות → חשבונות → הסר את חשבון גוגל, סמסונג וכו'. (אנדרואיד מאפשר מצב בעלים רק כשאין חשבונות. אחר כך מחזירים אותם.)
2. הפעל **אפשרויות מפתח**: הגדרות → אודות הטלפון → הקש 7 פעמים על "מספר Build". אחר כך באפשרויות מפתח הפעל **ניפוי באגים ב-USB**.
3. התקן במחשב את [Platform Tools](https://developer.android.com/tools/releases/platform-tools) (מכיל את `adb`) וחבר את הטלפון בכבל. אשר בטלפון את "התר ניפוי באגים".
4. בתיקיית platform-tools הרץ:
   ```
   adb shell dpm set-device-owner com.videoblocker.app/.AdminReceiver
   ```
   התשובה צריכה להתחיל ב-`Success`.
5. החזר את החשבונות לטלפון, וכבה את ניפוי הבאגים ב-USB.
6. פתח את האפליקציה – יופיע "✅ מצב בעלים פעיל". אפשר גם לבחור "חסום התקנת אפליקציות חדשות".

לביטול: באפליקציה → "הסר מצב בעלים" (דורש סיסמה). כל ההגבלות מוסרות והאפליקציות חוזרות.

> שים לב: אם שוכחים את הסיסמה במצב בעלים, אין דרך פשוטה לבטל. שמור אותה במקום בטוח.

## מגבלות שכדאי לדעת
- חסימת אתרים עובדת בדפדפנים המוכרים שברשימה. דפדפן אחר – הוסף את שם החבילה שלו לרשימת האפליקציות החסומות.
- זיהוי וידאו בתוך אפליקציות הוא זיהוי חכם, לא מושלם: אפליקציה שבונה נגן משלה בצורה לא סטנדרטית וגם לא מסמנת את השמע כסרט עלולה לעבור. מצב "אפליקציות מאושרות בלבד" סוגר את הפרצה הזו.
- מצב מחמיר עלול לחסום לפעמים גם שיחות וידאו או תצוגות דומות.
- כשהחסימה פועלת, ההשמעה שמתנגנת ברקע (גם מוזיקה) עשויה להיעצר יחד עם הווידאו.
- בלי מצב בעלים, מי שמכיר אנדרואיד יכול לעקוף דרך מצב בטוח. מצב בעלים חוסם זאת.
